TRALALA DESKTOP SITE

This package contains:
- index.html
- style.css
- script.js
- .nojekyll
- assets/character.png

STYLE:
- Mac-desktop-inspired landing page
- clickable folders
- openable windows
- copyable contract address
- mascot used as wallpaper character

SETUP:
1. Upload everything directly to your GitHub repo root.
2. In GitHub -> Settings -> Pages:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)

EDIT THESE LINKS IN index.html:
- x.com/yourprofile
- tiktok.com/@yourprofile
- pump.fun
- dexscreener.com

EDIT THIS TEXT IN index.html:
- PASTE_YOUR_CA_HERE

BEST RESULT:
- keep the mascot image transparent
- do not put text into the character image
- keep the CA and buttons in code
