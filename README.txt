LOS TRALALERITOS – GITHUB PAGES SKELETON

This package is built for:
- GitHub Pages
- simple static hosting
- easy image replacement later

FILES:
- index.html
- style.css
- script.js
- .nojekyll
- assets/image_1.webp
- assets/image_2.webp
- assets/image_3.webp
- assets/image_4.webp

HOW TO USE:
1. Upload all files to your GitHub repo root.
2. In GitHub -> Settings -> Pages:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
3. Replace these placeholders in index.html:
   - PASTE_YOUR_CA_HERE
   - your X link
   - your TikTok link
   - your chart link
4. Replace the placeholder image files in /assets with your final images.

IMAGE PLACEHOLDER SYSTEM:
- image_1.webp = hero main image
- image_2.webp = about section image
- image_3.webp = how to buy section background image
- image_4.webp = tokenomics / lower section image

IMPORTANT:
Keep the same file names if you want instant replacement without changing code.
