TRALALA – PROFESSIONAL ONE-PAGER

This version is:
- English only
- no gallery
- professional one-pager
- built for GitHub Pages
- optimized for a transparent mascot character layer

FILES:
- index.html
- style.css
- script.js
- .nojekyll
- assets/character.png

HOW TO USE:
1. Upload all files directly into your GitHub repo root.
2. In GitHub -> Settings -> Pages:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
3. Replace these placeholders in index.html:
   - PASTE_YOUR_CA_HERE
   - X link
   - TikTok link
   - Pump.fun link
   - Dexscreener link
4. Replace assets/character.png later if you create a better transparent mascot version.

BEST SETUP:
- Use a transparent PNG/WebP for the character
- Keep the background separate
- Keep text, CA, and buttons in code, not inside the image

CURRENT DESIGN LOGIC:
- clean premium blue background made in CSS
- transparent character layered on top
- copyable contract address
- simple social/action buttons
